# 思畅 AI：朗读接管与音频保存

## 行为

- 页面：`https://sichang.xyz/*` 聊天页。
- 两个发起入口，走同一条合成/播放/落盘流程：
  - 点击消息下方的「朗读」：脚本截下官方请求，**官方播放器不会出声**，改由脚本分段请求、边下边播。音色同样取面板里选定的那个，忽略官方请求自带的 `voice`。
  - 官方按钮组「生成」：直接读取官方输入框里的文字 + 面板音色，点「生成」或 `Ctrl/Cmd+Enter`。按钮组从左到右固定为「生成语音 → 加号 → 发送消息」，生成按钮随输入卡片重绘自动补回。音色会记住（`localStorage`），合成语速固定 1×。空文本时生成按钮禁用；输入框和面板共用同一份文字，不再单独存草稿或预填试听文本。生成按钮只显示图标：空闲时是喇叭（合成），合成中换成暂停图标，暂停后换成播放图标（继续），含义由 `title`/`aria-label` 说明；暂停会同时停住流式消费和当前播放，已完成的段仍可单独播放，继续后从原位置接着合成；`Ctrl/Cmd+Enter` 直接发起新的合成。
- 播放倍速与顶栏播放控件：标题栏只在有一路声音正在播放或停在原位时，显示「暂停/继续播放」按钮和倍速按钮；完全空闲时两者隐藏。播放按钮统一控制当前出声的那一路：顺序播放的段按 chain 暂停/继续，实时时间线或合成中的实时流按时间线暂停/继续，不必先找到对应分段。倍速按钮按 `1× → 1.25× → 1.5× → 2×` 循环，只作用于已下载完成的音频：分段音频立即变速；下载结束后仍在播放的时间线会从当前位置切到分段 `<audio>` 按新倍速继续，保持音高不变；合成中的实时流保持 1×，之后新建的分段音频沿用当前倍速。
- 记录操作：记录头一行依次显示折叠箭头、段数 `[共n段]`、摘要、总时长/合成进度 `n/m`、整条播放/暂停、整条重生成、删除图标和下载整条 WAV（不再显示创建时间戳）。图标按钮与分段行同尺寸、同间距，下载固定在行末。点记录头（含摘要标题）选中整条并收起/展开该条下方的分段列表（箭头随状态旋转，折叠后仍保留这一行）。官方输入框填入完整全文；摘要单行截断，不再展开全文。删除图标直接删除这条记录。
- 播放跟随输入框：顺序播放推进到新的一段、或实时时间线播到下一段时，官方输入框自动填入该段文本并同步选中状态；输入框正在被编辑或存有尚未提交的手动改动时不覆盖，避免冲掉草稿。
- 选中与编辑：点分段行（不是按钮）选中该段，官方输入框显示该段文本；编辑后点该段 ▶ 旁的 ↻ 图标，请求按输入框里的文本和面板当前音色发出，成功后写回该段文本、音色标签、整条摘要和可下载 WAV，并直接播放新音频。图标只作用于自己所在的那一段。点记录头或摘要选中整条，官方输入框显示完整全文，此时记录头的整条重生成会按输入框里编辑后的全文逐段原地重合成（分段数需与记录一致，否则沿用各段原文）。再次点同一条不会覆盖输入框里尚未提交的编辑；开始新合成或删除选中记录会取消选中。
- 面板挂载与折叠：面板嵌在官方输入卡片顶部，宽度跟随输入框；等页面水合完成后再挂载，没有可见输入区（如窄屏会话列表页）时整块隐藏，切会话或站点重渲染后自动重新挂载。默认收起；开始合成、播放都不再自动展开，面板保持用户记住的折叠状态，要看分段进度时自己点开。标题栏最左侧的折叠按钮使用和记录/分段行一致的小箭头：收起时朝右，展开时旋转 90° 朝下。没有记录时面板只保留顶栏，不展开 body，也不再显示空状态提示文字。音色选择放在面板标题栏，和倍速、清空、收起同排；「合成/暂停/继续」图标按钮在官方按钮组里，面板收起后仍可直接换音色/发起合成；面板底部留出间隙，与下方输入文字分开。单击标题栏收起/展开（标题栏内的按钮和下拉除外），手动折叠状态会记住；不再支持拖动和位置记忆。标题栏「清空」点一下原地换成「清空语音 / 清空文本」两个按钮：清空语音删除全部合成记录并释放音频，清空文本只清空官方输入框并取消选中；点任一按钮立即执行，点别处或 3 秒后收回成「清空」。有记录时「清空」才显示，没有记录直接隐藏；展开时没有对应内容的选项也隐藏。
- 官方输入区顶部的「语音合成」面板同步记录一次合成：开始时就按计划分段建好子条目，逐段显示 `待合成 → 合成中（时长随数据增长）→ 完成/失败`，记录头同时显示总进度 `n/m`；**每段一完成就能单独播放，不必等整条合成结束**；全部结束后把各段拼成一条 WAV，只用于整条下载。播放统一走分段顺序播放，记录头提供整条播放/暂停按钮。
- 实时播放的暂停/继续按钮就在当前播放分段的行里：合成下载完时整条可能还在时间线上播，行内按钮是暂停图标。暂停只停声音并保留进度，再点变「继续」并从中断处重排；播放时行内出现进度条（替代预览文字），点击按这一段已经播到的位置跳转，再换算成整条时间线上的位置。
- 记录头的整条播放/暂停按钮：没有播放队列时从第一段开始顺序播放；正在顺序播放时显示暂停，再点继续；实时时间线正在播或暂停时也复用这个按钮。暂停期间主按钮与当前分段行按钮状态一致。播放时记录头的时长位置显示整条「已播时间 / 总时长」，暂停后保留暂停点，停止播放后恢复只显示总时长。
- 分段子条目（核心 UI）：每条记录下按计划段建好列表，逐段显示文本、状态和时长；预览文字不再按字符数预先截断，保持单行显示，超出行宽的部分用省略号收起。点分段行选中该段并把文本填进官方输入框，播放推进时输入框也会跟着当前段走；点某段的 ▶/⏸ 就从该段开始**顺序播放**或暂停当前声音，播完自动接下一段。合成还没完成时，如果下一段还没好，行内按钮显示「等待下一段」，该段一完成自动接上。**所有控制都在分段行内，没有展开面板**：播放时进度条替代预览文字，时长位置改为「已播 / 总长」，点击进度条可跳转；该段音色以 `[音色名]` 形式显示在预览文字/进度条前面（完整名称在 title 里）；分段不再提供单独下载（要下载用记录头的整条 WAV）。合成中切换音色时，还没发出请求的段改用新音色，已开始的段保持原音色。单段「重生成」是每个分段行 ▶ 旁的 ↻ 图标按钮（不占文字宽度，说明写在 title/aria 里）：播放/暂停时点击会先停掉时间线或目标段再替换；合成进行中也能重生成**已经完成**的段，只替换该段并按长度差重排实时时间线；成功后自动播放新音频。生成中的分段行不显示行内播放按钮。
- 合成被中断（删除记录/分段或发起新的合成）或中途失败时，还没轮到的段标成「未合成」，已经收到部分数据的段保留为完成状态、仍可播放；整条 WAV 只拼接实际收到的段。
- 进度条：记录头用 `n/m` 表示合成阶段按已完成段数推进；各分段行空闲时显示状态和时长，播放时文字换成该段真实播放进度，点击可跳转。实时时间线与分段顺序播放共用当前段的这一条进度。
- 合成比实时快，长文本下载完时整条可能还在时间线上播：这段时间当前段行内是暂停图标，记录头按钮同步显示暂停；播完所有段恢复为可单独播放。暂停/继续只影响声音，不会重新请求；开始分段顺序播放前会先停掉实时时间线，避免叠音。
- 一次新的合成/朗读会停掉上一段朗读和面板里正在播放的音频，不会两路声音叠在一起。
- 面板与官方输入区共用文字：选中记录/分段、播放跟随都会通过原生 setter 写回官方 textarea；输入框正在编辑或存有未提交的手动改动时停止跟随，避免冲掉草稿。面板不再自带文本框、清空按钮和草稿记忆。
- 最多保留最近 20 条，删掉或挤掉的记录会释放 blob URL。

## 分段规则

- 先按句末标点（`。！？!?；;…`）和换行切句，再把短句攒到 **160 字**上限；超长句硬切。
- 首段先攒够 **0.5 秒**音频再起播：开头几个网络块常比实时慢，直接播会在第一句里留出 30–220ms 的补白。
- 单段失败重试 2 次；仍失败且一个字节都没收到时，把这段对半再拆（短于 40 字则放弃该段）。
- 播放当前段时预取下一段，缩短段间停顿。
- 长文本分段主要是为了稳定性：整段合成失败就全没了，分段后失败只影响一句。

## 接口契约

| 项 | 值 |
| --- | --- |
| 请求 | `POST /api/tts`，JSON `{text, voice, rate, format}`，`format` 当前为 `"pcm16"` |
| 响应 | `content-type: audio/pcm`，**流式**裸 PCM16，单声道 |
| 采样率 | 响应头 `X-Sample-Rate`（实测 `24000`），缺失时按 24000 处理 |

接管依赖两个约定：

- 官方请求由脚本用一帧静音响应顶替，否则官方播放器会弹「语音合成失败」。
- 脚本自己发的分段请求带 `X-Sichang-Segment: 1` 头，据此跳过接管，避免递归。

站点里 `/api/tts` 只有一个调用点：消息组件的 `useTts` hook（固定 `format: "pcm16"`）。「音频创作」页走的是 `/api/audio/jobs` 任务接口，不在接管范围；面板的手动入口直接用同一契约发请求，不模拟点击。

站点改版时先看 Network 里的 `/api/tts`：路径、请求体字段、采样率头或音频格式任一变化，都会表现为面板「失败」或没有声音。

## 分段与重生成

- 每段的 PCM 单独保存，WAV 按段顺序拼接；子条目顺序就是播放顺序和最终音频顺序。
- 点某段从该段开始**顺序播放**：首次播放时才按需生成该段的 WAV blob；播完自动接下一段，行内进度条跟着当前段切换，上一段恢复预览文字。暂停/继续、拖动进度只影响当前段；同一时间只放一条音频，开始新的会先停掉上一条。
- 合成中切到分段顺序播放时，实时时间线只停住声音、不中止合成，之后也不会自动切回时间线；等新段合成好由顺序播放接着播。
- 合成中顺序播放到尚未完成的段时，行内按钮显示「等待下一段」；该段完成后自动接着播，失败或未合成则跳过。
- 删除单段：每个分段行 ▶ 和 ↻ 右侧有 ✕ 按钮。合成中删除还没轮到（待合成）的段会直接跳过、不再发请求；删除正在生成的段会立即断开它的流、停止出声并移除，合成进度分母同步减一；删除已完成段会从整条 PCM 账本里扣掉并重新拼接 WAV。正在重生成的段不可删除；删光所有分段等同于删除整条记录。生成中的分段行不显示行内播放按钮，要跳过它直接点这一段的 ✕。
- 重生成只替换目标段，不动其他段；**音色取面板当前选中的音色**，语速与格式沿用这条记录的设置；成功后重拼 WAV、刷新总时长，并清掉该段旧的 blob URL 和播放状态，然后自动从该段开始顺序播放。顺序播放正播到或正等待这一段时，先停下这个队列。入口是该段 ▶ 旁的 ↻ 图标按钮。
- 合成进行中也可以重生成已经完成的段：更新总字节数和实时时间线进度，目标段在当前位置之前时平移后续偏移，正播到目标段内则从该段开头重排；未完成的段和正在重生成的那一段仍不可点。
- 选中某段时，重生成请求使用官方输入框里的文本；成功后把新文本写回该段和整条记录，摘要和后续整条重合成都会跟随。未选中该段时仍使用它保存的文本；请求失败时保留旧文本，避免文字与音频对不上。音色始终使用面板当前选择，换音色后直接点 ↻ 就会用新音色重做这一段。
- 重生成失败、返回空数据或采样率与整条不一致时，保留原段不变，该段图标短暂变红显示 `!`。
- 同一时间只允许一个段在重生成：目标段图标旋转并禁用，其他段的 ↻ 暂时禁用，但其他已完成段仍可播放；重生成只停目标段相关的播放，不打断其他段。
- 记录头的 ↻ 是整条重生成：按分段顺序复用逐段重生成，**原地替换所有分段，不新建记录**；结束后重拼一次 WAV，并从第一段开始自动播放。整条被选中且官方输入框全文的分段数与记录一致时，用输入框文本覆盖各段；否则沿用各段原文。合成进行中不可整条重生成，避免和正在写入的段抢数据。
- 要新建一条记录，直接在官方输入框写文字，再点面板里的「合成」。
- 合成中途断流时，已经收到的部分仍标记为可播放，和整条 WAV 里的内容一致。

## 单条消息删除

实现、完整接口契约、失败恢复和 React 状态同步见 `docs/logic/message-delete.md`。

- 入口：直接点官方消息上的「删除消息」按钮；没有脚本面板或额外管理 UI。所有会话统一接管，匿名/本地 `conv__anonymous__` 对话也走同一套接口流程。
- 官方 API 没有单条消息删除接口，官方界面默认会从这条起全部删除。脚本用官方迁移接口 `/api/conversations/import` 补回后面的消息：
  - 先读取官方最新消息，按 `DELETE /api/conversations/{id}/messages/{messageId}` 截断到目标消息。
  - 再把目标之后的原消息按原 ID、原 seq 重新 `import`；导入对已存在会话只增不改不删，所以必须依赖前面的截断。
- **接管官方删除按钮**：官方按钮（`aria-label="删除消息"`，兼容 title/英文名）在 `window` 捕获阶段被拦截；先 `preventDefault` 并停止传播，**不会执行官方原生截断，也不会在脚本失败时回退官方删除**。按钮没有消息 ID，因此用被点按钮的文档位置对应 `seq` 升序后的官方消息；同时要求按钮数量与官方消息数量一致，等待操作锁期间再次确认按钮列表未变化，数量或列表变化时拒绝操作。
- 可以只删除一条提问或一条回答，不要求整轮删除；删除后可能出现连续同角色消息。
- 不再弹确认框：点击官方「删除消息」立即执行截断、补回、写后 GET 校验；任何一步失败都会尝试补回原尾部，补回也失败时自动下载备份 JSON。失败信息只写控制台，不弹窗。
- **立即生效**：成功后不刷新页面。脚本通过官方前端 React context 的 `upsertConversation` 把剩余消息写回官方状态，由官方立即移除目标消息，并把保留消息的本地 `seq` 校正为服务端最新值；如果拿不到官方状态（站点内部结构改版），才回退为整页刷新，保证服务端与页面一致。
- 保留：消息 ID、seq、角色、正文、模型、创建时间。会丢失：被重建尾部消息的 `variants`、`thinking`、`imageSuggestions`、`webSources` 和附件/生成图。
- 限制：单条正文超过 20000 字会拒绝；空正文在重建时用零宽空格占位；一次导入最多 500 条，模块按 400 条分批；没有撤销入口。

## 会话克隆

实现与接口契约见 `docs/logic/conversation-clone.md`。

- 入口：聊天页顶栏「新建对话」左侧的复制图标，`aria-label`/`title` 都是「克隆会话」。按钮随官方顶栏重绘自动补回，SPA 切换会话后仍然可用。
- 所有会话（含匿名 `conv__anonymous__`）统一走官方 `create + import`，不再按会话类型分流；接口失败只在控制台报错。
- 读取当前会话的标题、模型、范围、`webSearch`/`reasoning` 和全部消息，直接新建一条标题为「原标题（副本）」的会话，不再弹确认框。
- 副本的消息使用新 ID 和连续 `seq`；保留角色、正文、模型和创建时间。官方 import 不接收 `meta`/`attachments`，所以分支变体、思考内容、网页来源不会复制；图片、生成图和附件的地址会以 Markdown 追加到正文末尾（`![图片](地址)` / `[附件](地址)`），至少能在副本里看到原图，但不是官方附件结构，不能重新编辑。
- 单条超过 20000 字、消息数超过 500 条的会话拒绝克隆；空正文用零宽空格占位。500 条是官方 import 迁移一次的上限。
- 导入后重新读取副本并校验条数、角色和正文；校验失败或任一步失败时删除刚建的副本，原会话不受影响。失败信息只写控制台。
- 成功后整页进入副本；原会话保持原样，可在副本里继续对话或继续删除/重生成。

## 手动添加 / 插入消息气泡

实现与接口契约见 `docs/logic/add-bubble.md`。

- 入口有两个：官方输入区「发送消息」左侧的加号（按钮组顺序：生成语音 → 加号 → 发送消息），`aria-label`/`title` 是「添加消息气泡」，把输入文字追加到会话末尾；每条消息操作行里的加号，`aria-label`/`title` 是「在下方插入消息」，把输入文字插入到该条消息下方。按钮随输入区/消息列表重绘自动补回；AI 回复期间发送按钮会变成「停止生成」，此时点击只会写控制台，不弹窗。
- 点击加号会弹出两个子选项：**添加提问**、**添加回答**（消息操作行是「在下方插入提问 / 在下方插入回答」）。选中哪个，就把官方输入框里的文字按该角色写入当前云端会话，**不触发 AI 回复**。
- 菜单在加号上方（顶部空间不足时改到下方），点菜单外、按 Esc 或滚动页面会自动关闭。
- **允许空内容**：输入框为空或只有空白时也能添加；服务端 import 会跳过空正文，所以脚本用零宽空格占位，气泡视觉上为空。
- 追加时消息 ID 和 `seq` 由脚本生成，`seq` 沿用官方 `nextSeq` 规则从服务端最新消息往后排；插入时新消息占用原尾部第一条的位置，原尾部整体后移，写入前先 `DELETE` 截断该尾部。
- 空会话添加第一条提问时，会把会话标题同步改成正文前 30 字（官方建会话的标题规则）；空内容或第一条选回答则保持「新对话」。插入不改标题。
- 写入成功后通过官方 React context 立即更新气泡并清空输入框，不刷新页面；拿不到官方状态时整页刷新。
- 输入区追加只支持登录后的云端对话；消息操作行插入也支持 `conv__anonymous__` 本地对话，走官方 React context 截断尾部并按顺序追加，由官方写入 IndexedDB。正文超过 20000 字、页面初始化未完成、AI 正在回复、消息列表与操作行数量不一致时拒绝操作，失败信息只写控制台。
- 只处理纯文本；输入区里挂着的附件/图片不会随气泡写入。插入会重建目标之后的消息，尾部消息的分支变体、思考内容、网页来源和附件元数据可能丢失。

## 消息级复刻（fork）

实现与接口契约见 `docs/logic/fork-message.md`。

- 入口：每条官方消息操作行（复制/朗读/编辑/删除那一行）最前面的分支图标，`aria-label`/`title` 都是「复刻到这条消息」。
- 点击后复制当前会话从第一条到该条（含该条）的消息，新建一条标题为「原标题（前N条）」的会话，并进入副本；原会话不变。
- 消息数量与页面操作行数量不一致（消息还在加载、正在流式回复、列表刚变化）时拒绝操作，不猜消息位置；失败只写控制台。
- 所有会话（含匿名 `conv__anonymous__`）同样支持；统一走官方接口，接口不可达时只在控制台报错，不再退回本地复制。
- 复刻不会携带分支变体、思考内容和网页来源；图片与附件地址会以 Markdown 链接追加到正文，纯文本结构下仍能看到原图；空正文用零宽空格占位。

## 边界

- 中断合成或开始下一次朗读时，已收到的部分照常保存成一条较短的记录。
- 单条上限 64 MB（约 22 分钟），超出后继续消费流但不再保存。
- 只在 `@grant none` 直接注入页面世界时可用，否则碰不到页面的 `fetch` 与 AudioContext。
