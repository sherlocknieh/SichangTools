# 思畅 AI：朗读接管与音频保存

## 行为

- 页面：`https://sichang.xyz/*` 聊天页。
- 两个发起入口，走同一条合成/播放/落盘流程：
  - 点击消息下方的「朗读」：脚本截下官方请求，**官方播放器不会出声**，改由脚本分段请求、边下边播。音色同样取面板里选定的那个，忽略官方请求自带的 `voice`。
  - 面板顶部手动输入：文本 + 音色 + 语速，点「合成」或 `Ctrl/Cmd+Enter`。音色与语速会记住（`localStorage`）。输入区下方实时显示字数与分段数（等于将要发出的请求数），随内容自动增高（上限 132px 后内部滚动），草稿也会记住（首次打开预填一句短试听文本）；空文本时「合成」禁用，「清空」只清输入并保持焦点。
- 记录操作：每条显示所用音色与语速；点文本展开/收起全文；「复制」复制原文；「重合成」用面板当前音色和语速再合成一条；「下载」保存 WAV。
- 面板可拖动：拖标题栏移动，位置会记住；双击标题栏复位成自动贴底（避开页面底部输入框）。标题栏已压缩，「清空」全部记录前会二次确认。
- 右下角「语音捕获」面板同步记录一次合成：合成中显示分段进度 `n/m`，可以「停止」；结束后把各段拼成一条 WAV，可播放/暂停、下载、删除。
- 播放倍速：面板标题栏的 `0.5×–2×` 选择器，作用于面板 WAV 和分段试听，立即换速且保持音高。实时合成播放固定 `1×`——Web Audio 的 `playbackRate` 会连音高一起升，保音高的变速只有 `<audio>` 能做。
- 分段子条目：每条记录下可展开「分段 n」，逐段显示文本和时长。每段都有自己的播放/暂停按钮、可点击跳转的进度条和「重生成」：单独重新请求该段、替换 PCM 并重拼整条 WAV；时间线还在播时点分段播放或重生成会先停掉整体播放，重生成期间其他段按钮暂时禁用。
- 进度条：合成阶段按已完成段数推进；播放阶段是真实播放进度，点击可跳转。
- 合成比实时快，长文本下载完时整条可能还在时间线上播：这段时间按钮保持「停止」，播完才自动变回「播放」；点「停止」立即静音并复位。播面板 WAV 前会先停掉时间线，避免叠音。
- 一次新的合成/朗读会停掉上一段朗读和面板里正在试听的音频，不会两路声音叠在一起。
- 面板会自动抬到底部输入框上方，避免挡住「发送」；标题右侧可收起成小条，状态会记住。
- 最多保留最近 20 条，删掉或挤掉的记录会释放 blob URL。

## 分段规则

- 先按句末标点（`。！？!?；;…`）和换行切句，再把短句攒到 **160 字**上限；超长句硬切。
- 首段先攒够 **0.5 秒**音频再起播：开头几个网络块常比实时慢，直接播会在第一句里留出 30–220ms 的补白。
- 单段失败重试 2 次；仍失败且一个字节都没收到时，把这段对半再拆（短于 40 字则放弃该段）。
- 播放当前段时预取下一段，缩短段间停顿。
- 长文本分段主要是为了稳定性：整段合成失败就全没了，分段后失败只影响一句。

## 接口契约

| 项 | 值 |
| --- | --- |
| 请求 | `POST /api/tts`，JSON `{text, voice, rate, format}`，`format` 当前为 `"pcm16"` |
| 响应 | `content-type: audio/pcm`，**流式**裸 PCM16，单声道 |
| 采样率 | 响应头 `X-Sample-Rate`（实测 `24000`），缺失时按 24000 处理 |

接管依赖两个约定：

- 官方请求由脚本用一帧静音响应顶替，否则官方播放器会弹「语音合成失败」。
- 脚本自己发的分段请求带 `X-Sichang-Segment: 1` 头，据此跳过接管，避免递归。

站点里 `/api/tts` 只有一个调用点：消息组件的 `useTts` hook（固定 `format: "pcm16"`）。「音频创作」页走的是 `/api/audio/jobs` 任务接口，不在接管范围；面板的手动入口直接用同一契约发请求，不模拟点击。

站点改版时先看 Network 里的 `/api/tts`：路径、请求体字段、采样率头或音频格式任一变化，都会表现为面板「失败」或没有声音。

## 分段与重生成

- 每段的 PCM 单独保存，WAV 按段顺序拼接；子条目顺序就是最终音频顺序。
- 每段可以单独播放：首次播放时才按需生成该段的 WAV blob，暂停/继续、拖动进度都只影响这一段；同一时间只放一条音频，开始新的会先停掉上一条（含整条试听）。
- 重生成只替换目标段，不动其他段；成功后重拼 WAV、刷新总时长，并清掉该段旧的 blob URL 和播放状态。
- 重生成失败、返回空数据或采样率与整条不一致时，保留原段不变，按钮短暂显示「失败」。
- 同一时间只允许一个段在重生成，期间该条所有分段按钮禁用。
- 合成中途断流时，已经收到的部分仍标记为可播放，和整条 WAV 里的内容一致。

## 边界

- 点「停止」或开始下一次朗读时，已收到的部分照常保存成一条较短的记录。
- 单条上限 64 MB（约 22 分钟），超出后继续消费流但不再保存。
- 只在 `@grant none` 直接注入页面世界时可用，否则碰不到页面的 `fetch` 与 AudioContext。
