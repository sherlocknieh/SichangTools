# 已知坑

现象 → 原因 → 规避方式。遇到新的站点改版或环境问题，先在这里追加，再改代码。

## 脚本装了却完全没反应

**现象**：开发时 `npm run dev` 已启动、管理器里也看到了脚本，但目标页没有任何效果，控制台报 `violates the following Content Security Policy directive` 或 `Refused to load the script`。

**原因**：目标站点的 CSP 拦掉 `localhost:5173` 注入，脚本根本没执行。

**规避**：按 `development.md` 的说明，把 userscript-dev 技能里的 `dev-kit.mjs` 拷到 `.dev/`，用「拉取构建产物再注入」的方式调试；构建产物写 `.dev/build/`，不动要提交的 `dist/`。

## 热更新后出现两份面板

**现象**：改一次源码，页面上出现两套面板，或朗读请求被接管两次导致递归。

**原因**：脚本管理器重新执行同一份脚本时，上一轮的监听器、注入节点和 `fetch` 包装还在。

**规避**：入口通过 `unsafeWindow.__USERSCRIPT_TEARDOWN__` 拆除上一轮再初始化；handler 必须返回清理函数并还原 `window.fetch`。

## 删除失败：未登录或不在云端

**现象**：点官方「删除消息」后控制台出现 401/404，无法删除。

**原因**：当前对话是未登录时的本地加密对话（ID 里通常是 `conv__anonymous__`），没有云端消息接口；或者登录态已失效。

**规避**：登录后打开云端对话再用；本地对话仍走官方原有删除，脚本不直接改 IndexedDB。

## 单条删除后变体/图片/附件消失

**现象**：删除一条消息后，后面某些消息的分支变体、思考、图片建议、网页来源或附件不见了。

**原因**：官方 `import` 只接收 `id/seq/role/content/model/createdAt/state`，不接收 `meta` 和 `attachments`；任何「截断 + 补回」都会重建目标之后的整段尾部。

**规避**：没有确认框，点击即执行；只有纯文本尾部可以无损重建。含变体或附件的对话，先下载备份或接受尾部元数据丢失；补回失败时脚本会自动下载备份 JSON。

## 官方删除按钮无法安全对应消息 ID

**现象**：点击官方「删除消息」后控制台出现「无法安全对应官方删除按钮与消息 ID」或「官方消息列表已变化」。

**原因**：官方按钮不携带 `msgId`；脚本只有在官方消息数量、文档顺序与被点按钮都能唯一对应时才会删除。列表仍在加载、另一窗口正在修改、出现隐藏/额外删除按钮或 DOM 重渲染时会安全拒绝。

**规避**：刷新页面、等待消息加载完成后重试；**不要绕过脚本点官方删除**，脚本已阻止官方原生「从这条起全部删除」回退。匿名/本地 `conv__anonymous__` 对话不属于接管范围。

## 删除后页面没有立即更新

**现象**：服务端已删除，但官方页面仍显示目标消息。

**原因**：脚本优先通过官方 React context 的 `upsertConversation` 写回剩余消息；站点改版后如果 context 结构变化，这一层会失败并自动整页刷新。

**规避**：看到页面自动刷新说明走了回退路径，数据仍以服务端为准；若既不更新也不刷新，先刷新页面并反馈站点改版。

## 单条删除写入后校验失败

**现象**：控制台出现「写入后校验失败」或导入被跳过，消息顺序和预期不一致。

**原因**：`/api/conversations/import` 的迁移配额/上限变化、单条超过 2 万字、或操作期间另一个窗口往对话里发了新消息。

**规避**：先刷新读取最新消息再操作；不要把删除点放在超长消息之前；校验失败时脚本会尝试补回原尾部，补回也失败就自动下载备份 JSON，避免刷新页面。

## 顶栏没有「克隆会话」按钮

**现象**：聊天页顶栏只有「新建对话」，找不到复制图标。

**原因**：官方顶栏结构或按钮 aria-label 改版，`constants.js` 里的 `OFFICIAL_CHAT_HEADER_SELECTOR` / `OFFICIAL_NEW_CHAT_SELECTOR` 匹配不到；移动端窄屏也可能不渲染同一套顶栏。

**规避**：先核对顶栏 DOM 和按钮 aria-label，只改 `constants.js` 里的选择器；按钮缺失时不影响朗读、删除等其他功能。

## 克隆失败

**现象**：点「克隆会话」没有出现副本，控制台有 401/404 或其他错误。

**原因**：登录态失效，或纯本地匿名会话的接口不可达且官方 context 里没有加载完消息。

**规避**：登录后重试；匿名会话会优先走服务端接口，失败再退回本地 context。没有弹窗，失败信息看控制台 `[SichangTools]`。

## 克隆后副本消息变少

**现象**：副本里的消息数量少于原会话。

**原因**：官方 `import` 迁移一次最多接收 500 条消息，超出部分会被服务端跳过。

**规避**：消息数超过 500 条的会话脚本会直接拒绝；如果站点放宽/收紧上限，以 `CONVERSATION_IMPORT_MAX_MESSAGES` 和写入后校验为准。

## 加号按钮不见了或点了没反应

**现象**：官方输入区右侧找不到加号，或点击后没有新增气泡。

**原因**：官方输入区结构或「发送消息」aria-label 改版，`OFFICIAL_SEND_SELECTOR` 找不到；或者 AI 正在回复，发送按钮已被换成「停止生成」。

**规避**：等回复结束后再试；仍然缺失时只改 `constants.js` 里的 `OFFICIAL_SEND_SELECTOR`/`OFFICIAL_ATTACH_SELECTOR`，不要改写入逻辑。

## 加号无法写入

**现象**：点加号没有新增气泡，控制台有错误。

**原因**：当前是 `conv__anonymous__` 本地对话、URL 还是 `/chat`（还没创建云端会话）、登录态失效，或 AI 正在回复。

**规避**：登录后打开一条云端会话再添加；新会话先正常发送一条消息创建会话。空输入是允许的，会写入零宽空格并显示为空气泡。

## 加号不处理附件

**现象**：输入区已经挂了图片/文档，点加号后只有文字被写入。

**原因**：脚本只读取 textarea 文本，import 也不接收 `attachments`。

**规避**：附件需要走官方发送流程；脚本不会把附件一起写入气泡。

## fork 按钮缺失或点了不生效

**现象**：消息操作行没有分支图标，或点击后没有进入副本。

**原因**：官方「复制消息」按钮选择器/操作行层级改版；或页面消息数量与操作行数量不一致（正在加载、流式回复、列表刚变化），脚本安全拒绝。

**规避**：等消息加载/回复结束再点；仍缺失时只改 `constants.js` 里的 `OFFICIAL_COPY_SELECTOR`。失败原因看控制台 `[SichangTools]`。

## 面板失败或没有声音

**现象**：点击朗读或「合成」后提示失败，或完全无声。

**原因**：站点接口变化。先看 Network 里的 `/api/tts`：路径、请求体字段、`X-Sample-Rate` 头或音频格式任一变化都会失效。

**规避**：按 `features/sichang.md` 的「接口契约」逐项核对；只改 `constants.js` 顶部与 `synthesis.js` 的请求/接管实现，不要把新契约散落到业务代码里。
